A round-based tactical FPS in three.js: mouse look, accelerated WASD with crouch, a rifle with recoil and spread, six bots that patrol, spot and shoot back, 90-second rounds with a win or a loss, and a HUD with health, ammo, timer and targets. All geometry and materials built in code; no assets, no network, no build step.

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
